# مصاريف رحلات العمل — تطبيق خاص للآيفون

## المحتويات
- `index.html`: التطبيق بعد تحسين الواجهة ودعم تصدير/مشاركة PDF في Safari.
- `manifest.webmanifest`: تعريف التطبيق وأيقونته.
- `sw.js`: تخزين ملفات التطبيق الأساسية للعمل دون اتصال بعد أول زيارة.
- `icons/`: أيقونات التطبيق.

## النشر الخاص المجاني
1. ارفع **محتويات هذا المجلد** إلى استضافة مواقع ثابتة تدعم HTTPS (مثل GitHub Pages أو Netlify). لا ترفع ملف ZIP نفسه فقط.
2. افتح رابط الموقع المنشور في Safari على الآيفون.
3. اضغط زر المشاركة في Safari ثم اختر «إضافة إلى الشاشة الرئيسية»، ثم «إضافة».
4. افتح التطبيق من الأيقونة. بعد أول تحميل، يمكن فتح واجهته دون اتصال بالإنترنت.

## تنبيه مهم عن البيانات
الرحلات والصور محفوظة محلياً في IndexedDB على المتصفح/الجهاز. لا تحذف بيانات Safari أو بيانات الموقع قبل تصدير نسخة من تقاريرك؛ ولا تنتقل البيانات تلقائياً إلى جهاز آخر. هذا التطبيق لا يرسل بيانات الرحلات إلى خادم.

## ملاحظات
- لا يحتاج حساب Apple Developer ولا نشر App Store.
- يجب استخدام HTTPS حتى يعمل التثبيت وService Worker.
- PDF: يحاول فتح قائمة المشاركة في iOS، ثم يستخدم تنزيل المتصفح كخيار احتياطي.
